# Python

A personal collection of Python programs organized by skill level — from fundamentals through advanced topics.

## Repository Structure

```
Python/
├── Basic Python/           # Fundamentals: syntax, variables, loops, conditionals
├── Intermediate Python/    # Functions, data structures, file handling, OOP
├── Advanced Python/        # More complex programs and concepts
└── tree_structure/         # (project/folder structure reference)
```

## About

This repository is a running log of Python practice — programs written while learning and
strengthening core programming concepts, moving progressively from basic scripts to more
advanced, real-world-style code.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/sunilnarayan419-ui/Python.git
cd Python
```

Each script can be run directly with Python 3:

```bash
python "Basic Python/<script_name>.py"
```

## Requirements

- Python 3.x
- No external dependencies unless noted inside an individual script
